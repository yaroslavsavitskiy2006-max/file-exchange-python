# Практическая работа №8: Файловая почта

Учебный проект на Python для реализации системы безопасного обмена файлами. Проект включает в себя инструменты для поиска, хеширования, упаковки и верификации данных.

## Основные возможности

- **Сканирование (Scan):** Рекурсивный поиск файлов в рабочей директории с поддержкой фильтрации по маске (`fnmatch`) и минимальному размеру. Результаты сортируются по имени и относительному пути.
- **Хеширование (SHA-256):** Поблочное чтение файлов (по 4096 байт) для вычисления контрольной суммы, что позволяет работать с файлами любого размера.
- **Упаковка (Pack):** Создание защищенного ZIP-архива, содержащего сам файл и `manifest.json` с метаданными (отправитель, получатель, хеш-сумма).
- **Безопасный прием (Receive):** 
    - Проверка контрольной суммы (SHA-256) перед сохранением.
    - Валидация имени файла (защита от Path Traversal).
    - Защита от перезаписи существующих файлов (режим `xb`).
- **Отчетность:** Генерация CSV-отчетов о найденных файлах.

## Структура проекта

- `file_exchange_starter.py` — основной скрипт системы.
- `test_selfcheck.py` — набор Unit-тестов для проверки всех функций системы.
- `tamper_demo.py` — утилита для имитации повреждения пакета (тестирование защиты).
- `workspace/` — рабочая область (создается автоматически):
    - `data/` — исходные файлы.
    - `outbox/` — подготовленные к отправке пакеты.
    - `inbox/` — принятые файлы.

## Использование

### 1. Подготовка учебной среды
Создает структуру папок и тестовые файлы:
```bash
python file_exchange_starter.py prepare
```

### 2. Поиск файлов
```bash
python file_exchange_starter.py scan --pattern "*.txt" --min-size 10
```

### 3. Отправка файла (Упаковка)
```bash
python file_exchange_starter.py pack --file notes.txt --sender team_A --recipient team_B
```

### 4. Прием файла (Распаковка)
```bash
python file_exchange_starter.py receive --package workspace/outbox/team_A__team_B__notes.zip --recipient team_B
```

## Тестирование
Для запуска автоматической проверки выполните:
```bash
python test_selfcheck.py
```

## Требования
- Python 3.9+
- Стандартные библиотеки (`hashlib`, `pathlib`, `zipfile`, `json`, `csv`)
