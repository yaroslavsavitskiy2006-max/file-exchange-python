# Практическая работа № 8: Файловая почта

Учебный проект по дисциплине «Технология программирования». Реализация безопасного обмена файлами через ZIP-пакеты с проверкой целостности (SHA-256) и манифестом.

## Функционал
- **Поиск и фильтрация**: Рекурсивный поиск файлов в `workspace/data` с использованием масок (`fnmatch`) и фильтрацией по минимальному размеру.
- **Хеширование**: Расчет SHA-256 для бинарных файлов с использованием поблочного чтения (4096 байт) для оптимизации памяти.
- **Упаковка**: Создание ZIP-архивов с автоматической генерацией `manifest.json`.
- **Безопасный прием**: 
    - Проверка контрольной суммы (SHA-256).
    - Валидация имени файла (защита от Path Traversal).
    - Проверка адресата (recipient).
    - Запись в режиме `xb` (защита от перезаписи).
- **Отчетность**: Выгрузка результатов сканирования в формат CSV.

## Структура проекта
- `file_exchange_starter.py` — основной скрипт (CLI приложение).
- `test_selfcheck.py` — unit-тесты для проверки всех модулей.
- `tamper_demo.py` — утилита для демонстрации защиты (создает поврежденный пакет).
- `workspace/` — рабочая директория (data, inbox, outbox).

## Использование

### Подготовка окружения
```bash
python file_exchange_starter.py prepare
```

### Сканирование файлов
```bash
python file_exchange_starter.py scan --pattern "*.txt" --min-size 10
```

### Отправка файла
```bash
python file_exchange_starter.py pack --file notes.txt --sender team_A --recipient team_B
```

### Прием файла
```bash
python file_exchange_starter.py receive --package workspace/outbox/team_A__team_B__notes.zip --recipient team_B
```

## Тестирование
Запуск автоматических тестов:
```bash
python test_selfcheck.py
```

Для проверки защиты от подмены:
1. Создайте пакет (`pack`).
2. Испортьте его: `python tamper_demo.py <путь_к_пакету>`.
3. Попробуйте принять `corrupted_...zip`. Программа выдаст `ValueError: Контрольная сумма SHA-256 не совпадает`.
